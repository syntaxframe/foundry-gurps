# GURPS (GMentor) для Foundry VTT

Система GURPS 4-й редакции для Foundry VTT v14.

## Что умеет

- Анкета персонажа и строка очков: сколько потрачено на атрибуты, черты и умения и сколько осталось.
- Сама считает атрибуты, вторичные характеристики, урон (укол, замах, кулак, пинок), нагрузку, уклонение, парирование и блок.
- Раны и усталость с порогами последствий (измотан, без сознания, броски от смерти).
- Локации попадания с СП, броском на случайное попадание и штрафом к прицельному удару.
- Временные состояния GMentor (позы, оглушение, боль, опьянение и др.) с полными описаниями из книги.
- Стоимость черт: уровни, самоконтроль, улучшения и ограничения.
- Уровни умений и заклинаний по вложенным очкам.
- Броски 3d6 с критами по правилам и броски урона прямо из записи вида `sw+1 cut`.

## Установка

Скопируйте папку `gmentor` в `Data/systems/` или сделайте туда симлинк. Перезапустите Foundry и создайте мир на системе «GURPS (GMentor)».

Язык интерфейса переключается в *Configure Settings → Language*. Описания состояний есть только на русском.

## Как пользоваться

- **Атрибуты и вторичные характеристики.** В поле вводится итоговое значение, как в GMentor. Стоимость лист посчитает сам и покажет рядом в скобках. Красная цифра — значение вне рекомендованных пределов книги или изменённое состоянием.
- **Раны и усталость.** Вводится, сколько потеряно. Можно выражением, например `3+5+2`. Достигнутые пороги подсвечиваются.
- **Состояния.** Кнопка «+» в блоке «Состояния» открывает список: ⓘ справа показывает полное описание. Включать состояния можно и значками на токене. Штрафы применяются сами, поза может быть только одна. Описание активного состояния раскрывается кликом по его названию на листе.
- **Броски.** Клик по названию характеристики, по урону, по защите или по уровню умения. Shift+клик сначала спрашивает модификатор.
- **Оружие.** Укажите у предмета урон и название умения, затем отметьте его как «Надето». Оружие появится в блоке «Оружие в руках» с уровнем атаки.
- **Бонусы от черт** (например, +1 к уклонению от «Боевых рефлексов»). Добавьте черте Active Effect с ключом `system.bonuses.dodge`. Есть также `st`, `dx`, `iq`, `ht`, `hp`, `fp`, `will`, `per`, `speed`, `move`, `parry`, `block`, `sm`, `fright`, `strikingSt`, `liftingSt`, `dr` (СП на всё тело).

## Чего пока нет

Импорта из GMentor/GCS, оформления списков черт, умений и снаряжения в стиле GMentor, значений умений по умолчанию, техник, брони по локациям, контейнеров и стрелкового оружия.
